questions, answered

the useful bits.

Can I install VocaWin today?＋

Yes. An unsigned beta is on GitHub Releases. Windows will likely warn that the publisher is unknown. That is SmartScreen doing its job. More info, then Run anyway if you trust the file. This is not a Microsoft Store listing and not a signed public release. Read the setup guide first, and file an issue if something breaks.

Is there a nightly?＋

Yes. A moving unsigned build from main is on the nightly GitHub Release. Same SmartScreen story as the tagged builds. Prefer the latest tagged Release if you want the last cut we named. Nightly is for testers who want today's tree.

Does my voice stay on this PC?＋

That is the design. After a Whisper model is downloaded, recording and speech-to-text run on this Windows machine. No Voca cloud, no Voca account, no hosted speech API. The first model download does need a network. The build is unsigned and tester-only.

Do I need VocaGateway?＋

Not for VocaWin dictation. VocaWin speech-to-text stays on this PC. Settings can optionally start a local VocaGateway container so phones and other clients can pair with this machine. Gateway is not on-device: audio that uses it leaves this PC for the container.

What is VocaHQ?＋

VocaHQ is the family home for VocaLinux, VocaMac, VocaWin, VocaPhone, and VocaGateway. The directory, privacy paths, and project status live on vocahq.com.

What hotkey will it use?＋

The beta defaults to Right Alt for push-to-talk, with an optional double-tap toggle. You can change the hotkey in Settings. That default can still move.

Which languages will it support?＋

Support follows the Whisper model you download. The first-run default is the small English tiny.en model, with language set to automatic. We list only what the selected model can actually transcribe.

Is it free and open source?＋

Yes. The repository is licensed under AGPL-3.0-or-later, stays free, and does not require a Voca account. Sibling Voca apps also use AGPL-3.0.
