questions, answered

the useful bits.

Can I install VocaWin today?＋

No. There is no public installer, Microsoft Store listing, or shipping release. Star or watch the repository if you want to see a build land.

Does my voice stay on this PC?＋

That is the design. After a Whisper model is downloaded, recording and speech-to-text are meant to run on this Windows machine with no Voca cloud. The first model download does need a network. Do not treat “coming soon” as a guarantee of the shipping build.

Do I need VocaGateway?＋

Not for VocaWin. VocaWin is being built as an on-device Windows app. VocaGateway is optional self-hosted infrastructure for other Voca clients. Gateway mode is not on-device: configured audio travels to the host you chose.

What is VocaHQ?＋

VocaHQ is the family home for VocaLinux, VocaMac, VocaWin, VocaPhone, and VocaGateway. The directory, privacy paths, and project status live on vocahq.com.

What hotkey will it use?＋

The in-progress settings default to Right Ctrl for push-to-talk, with an optional double-tap toggle. That can still change before a public release.

Which languages will it support?＋

Support will follow the Whisper model you download. The planned first-run default is the small English tiny.en model, with language set to automatic. We will list only what the selected model can actually transcribe.

Is it free and open source?＋

Yes. The repository is licensed under AGPL-3.0-or-later, stays free, and does not require a Voca account. Sibling Voca apps also use AGPL-3.0.
